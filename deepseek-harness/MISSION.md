# Mission: DeepSeek Harness 原理、插件开发与二次开发

## Why

学习本机 DeepSeek Harness 的运行机制，能够自行开发、调试和维护插件，并根据真实需求进行二次开发。项目持续更新，因此还要能识别上游变化对已有知识和插件的影响。

## Success looks like

- 能沿源码解释一次输入如何触发模型请求、工具执行和下一步，以及何时结束。
- 能区分 Cordis 插件、服务、工具、事件、Session、turn 和 step。
- 能做出一个可加载、可卸载、有输入输出定义和行为验证的工具插件。
- 能判断需求应落在配置、工具、服务提供者、事件监听器、SDK 还是循环实现。
- 能在更新后定位受影响接口，调整插件并完成针对性验证。

## Constraints

- 中文教学，保留英文代码标识符。
- 用户已确认“能读代码，但 agent 循环还不熟”；先教执行过程，按需解释 TypeScript。
- 学习对象是本地仓库，首个基线为 `ddefc45fbc7f8e46dd73185e68295696d1297887`（`0.1.6-alpha.2`）。
- 课程记录基线、源码证据与复核点；学习文件放在本目录，源码仓库作为只读资料。
- 每课一个可验证目标；先提供无需 API key 的互动反馈，再逐步进入真实插件实践。

## Out of scope

用户尚未指定额外排除项。当前教学顺序优先运行机制和插件，不先展开桌面打包或全仓逐文件精读。
