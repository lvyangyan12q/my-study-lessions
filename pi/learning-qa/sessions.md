## 一、会话基础
- Pi 把一次对话保存为一个 **session**；**活动分支（active branch）** 才提供下一次模型请求的历史。
- 默认自动保存；`--no-session` 开临时会话（退出后不能恢复）。
- `pi --continue`：恢复**当前工作目录**下最近的会话。
- `pi --resume`：打开会话选择器。交互里 `/resume` 同效，`/new` 开新会话。
- `/name` 命名；`/session` 查看会话文件、ID、消息数、token 用量与花费。

## 二、分叉三种（核心区别）
| 动作 | 结果 | 何时用 |
|---|---|---|
| `/tree` | 在**同一个会话文件内**移动 | 相关备选应留在一起 |
| `/fork` | 从更早的**用户消息**新建会话 | 该备选应成为独立工作 |
| `/clone` | 把**当前活动分支**复制进新会话 | 想要当前状态的独立副本 |

- 在 `/tree` 里选中用户消息 → 文本回到编辑器，改完提交即造出另一分支。
- 离开某分支时，Pi 可把它**摘要**并挂到你进入的分支上。

## 三、上下文（关键认知）
- 模型收到的是**活动分支**，不是整个会话文件的所有分支。
- Pi 把该历史 + 系统提示 + 发现的上下文文件 + 可用工具 + 已加载的 skill 描述组合起来。
- 接近模型上限时通常**自动压缩**旧历史；`/compact` 手动。**压缩不删除原始会话条目**。

## 四、存储与导出
- 默认存在 `~/.pi/agent/sessions/`，**按工作目录分组**。
- 改位置：`--session-dir` > `PI_CODING_AGENT_SESSION_DIR` > `sessionDir` 设置（**CLI 优先级最高**）。
- `/export` 导出 HTML 或 JSONL；`/share` 上传拿查看链接（Radius artifact 或私有 gist）。**分享前先 review**。
- `/bug [描述]`：准备一个私有问题报告（可含/不含会话记录）。
