Quickstart：从装到第一句话

这一篇是「把 Pi 跑起来」的最短路径，五步走完。它同时是后面所有主题的起点：工作目录、模型、会话，都在这里第一次出现。

这一课带走什么

离开时你能：① 说出 quickstart 的五步；② 在任何一台机器上把 Pi 从零跑起来；③ 看懂文末那张「定制选型器」表。

五步全貌

① 安装

方式命令要点
安装脚本（macOS / Linux）curl -fsSL https://pi.dev/install.sh | sh锁定全部依赖；用 pi update 更新
npmnpm install -g --ignore-scripts @earendil-works/pi-coding-agent需要 Node.js 22.19+；不锁定传递依赖
Nixnix profile add github:earendil-works/pi/stable从源码构建；pi update 管不了 Nix 安装

验证：pi --version。Windows 见 Windows Setup，Android 见 Termux Setup。

② 启动（注意「工作目录」）

cd /path/to/folder
pi

工作目录是关键参数：Pi 靠它发现相关文件、指令、配置，也用它给保存的会话分组。换个目录，看到的就是另一套上下文。

③ 选模型

先分清两个词：model 是生成回答的模型；provider 是 Pi 用来访问该模型的服务 / 账号。一个 provider 下可以有多个 model。
/login

选一个 provider，按提示用订阅或存 API Key；之后想换具体模型再 /model。受支持的 provider、环境变量认证、本地模型、自定义端点见 models.md。

④ 给任务

Pi 会显示它做的每一次读取、搜索、命令和编辑——但不会每次工具调用前都问你。在编辑器里输入 @ 可以搜文件，不用写全路径。三个例子：

Summarize @meeting-notes.md and save the action items to action-items.md.
Explain how this repository is structured and how to run its checks.
Compare @previous.csv with @current.csv and summarize the important changes.
安全前提：重要工作先有版本控制或备份；不可信 / 无人值守的场景，用容器或其它沙箱。见 security.md。

⑤ 继续

会话自动保存。退出后，在同一工作目录里恢复最近一次：

pi --continue

要挑别的会话用 /resume；命名、分支、压缩、导出、分享见 sessions.md。

定制选型器（重点）

从满足需求的最小机制起步。这张表就是第 2 课「定制阶梯」的操作版：

需求先用
给某文件夹常驻指令AGENTS.md
从 / 菜单复用一段提示词Prompt template
加任务专用说明和配套文件Skill
加可执行工具、命令、事件处理器Extension
造自定义终端组件Terminal UI
接一个不受支持的模型服务Custom provider
安装 / 分发多个资源Pi package

卸载

npm：npm uninstall -g @earendil-works/pi-coding-agent；安装脚本：重跑并选 Uninstall Pi；Nix：nix profile remove pi。三者都不会删除 ~/.pi/agent/ 里的配置、凭据、会话或已装 Pi 包。

主要出处

读原文：docs/quickstart.md。中英对照见 quickstart 中英对照。
