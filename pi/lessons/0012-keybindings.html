Keybindings：给动作绑键

Pi 把功能拆成**命名的动作**（如 app.session.new），键只是动作的绑定。想改键或禁用某键，改的是一张「动作 id → 键」的表。

这一课带走什么

知道改键位改哪个文件、改完做什么才生效；会写键语法、会禁用某动作的键。

核心：动作是主，键是绑定

键语法

写成 modifier+key：修饰键 ctrl / shift / alt / super，可叠加（如 ctrl+shift+alt+x）。

  • 字母 a-z、数字 0-9、功能键 f1–f12、符号。
  • 特殊键名：escape、enter、tab、space、backspace、delete、home/end、pageUp/pageDown、方向键等。
  • super 需要终端支持 Kitty 键盘协议（能把 super 单独上报），否则可能不生效。

检索练习（合上再答）

改键位的流程是什么？

编辑 <agent-dir>/keybindings.json（动作 id → 键或键数组）→ 运行 /reload 生效。

super 绑定需要什么？

  • 键盘协议
  • 内核协议
  • 主题配置
  • 模型支持

Windows 上排队 follow-up 用哪个键？

  • Ctrl+Q
  • Ctrl+E
  • Alt+Q
  • Alt+E
