核心三：三条出口

出口触发后果
错误 / 中止message.stopReason 为 "error" / "aborted"finishTurn（决策被忽略）→ turn_end → agent_end → 直接 return
finishTurn 决定 end钩子返回 { action: "end" }turn_end 后 → agent_end → return
正常收敛没有工具调用、没有 steering、没有 follow-up跳出外层 → agent_end → return
对照手搓：7 行骨架只处理「正常收敛」这一条出口。真实实现还要接住 error / aborted、还要被 finishTurn 提前喊停——这就是「能跑的 demo」和「能用的 agent」的差距。
