Pi

Pi is an extensible AI agent that works from your terminal. Give it a goal and a working folder, and it can inspect files, run commands, edit content, and work through multi-step tasks.
Pi 是一个可扩展的、在终端里工作的 AI agent。给它一个目标和一个工作目录，它就能查看文件、运行命令、编辑内容，并完成多步任务。
Use Pi for software development, research notes, writing projects, data files, or hobby work. You can use Pi as is, prompt it to adapt itself to your workflow, or build other applications powered by Pi using the SDK.
你可以把 Pi 用于软件开发、研究笔记、写作项目、数据文件或业余折腾。既能原样使用，也能让它按你的工作流自我改造，还能用 SDK 构建由 Pi 驱动的其它程序。

Start using Pi / 开始使用 Pi

New to Pi? Follow the Quickstart to install Pi, connect a model, and complete your first task.
刚接触 Pi？跟着 Quickstart 走：安装 Pi、接入一个模型、完成第一个任务。
If Pi is already installed, choose what you want to do:
如果已经装好了，按你想做的事挑：
Use Pi interactively to add files, run commands, direct ongoing work, and export results.
交互式使用 Pi：添加文件、运行命令、指挥进行中的工作、导出结果。
Choose a model or connect a subscription, API key, local model, or compatible endpoint.
选择模型，或接入订阅、API Key、本地模型、兼容端点。
Continue or branch a session to resume work or explore another approach without losing history.
继续或分叉会话：恢复工作，或另开一条路探索，同时不丢历史。
Configure Pi for your preferences, working folders, instructions, and reusable resources.
配置 Pi：偏好、工作目录、指令，以及可复用资源。
Understand how Pi works, including tools, context, sessions, and the agent loop.
理解 Pi 如何工作：工具、上下文、会话，以及 agent 循环。

Customize Pi / 定制 Pi

Pi can reuse prompts, load specialized instructions, add executable integrations, change its terminal interface, connect model services, and distribute these resources as packages.
Pi 可以复用提示词、按需加载专门指令、加入可执行集成、改变终端界面、接入模型服务，并把这些资源打包分发。
Use the Quickstart customization chooser to select the smallest mechanism that meets your need.
用 Quickstart 里的「定制选型器」 挑满足需求的最小机制。

Automate or embed Pi / 自动化或嵌入 Pi

Use print mode for one-off and scripted tasks.
一次性、脚本化任务用 打印模式。
Use JSON event stream mode to consume structured events from one run.
想消费一次运行中的结构化事件，用 JSON 事件流模式。
Use RPC mode to control a separate Pi process.
想控制一个独立的 Pi 进程，用 RPC 模式。
Use the TypeScript SDK to run Pi inside an application.
想在应用内部运行 Pi，用 TypeScript SDK。

Find reference and setup information / 查阅与安装信息

Use the reference pages to look up CLI options, settings, providers, keybindings, and environment variables.
用参考页查 CLI 选项、设置、Provider、按键绑定、环境变量。
For platform-specific help, see Terminal Setup, Windows, tmux, Termux on Android, or Containerization.
平台相关问题看 终端设置、Windows、tmux、Android/Termux 或 容器化。

Work safely / 安全地使用

Pi's tools and extensions run with the permissions of the Pi process. Project trust controls which project resources Pi loads, but it does not sandbox tool calls. Review Security before using untrusted files, repositories, extensions, or unattended automation.
Pi 的工具和扩展以 Pi 进程的权限运行。项目信任决定 Pi 加载哪些项目资源，但它并不为工具调用提供沙箱。在接触不可信的文件、仓库、扩展，或做无人值守自动化之前，先读 Security。
