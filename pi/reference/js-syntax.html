写 agent 循环够用的 JS / TS 语法

你懂流程、只是不会写。这一页只给「写那个 7 行循环」需要的语法，每块附一句：它在这段循环里扮演什么。看完就能自己把 exercises/0001-agent-loop.mjs 写出来。

先消一个歧义

练习文件是 .mjs——这是纯 JavaScript（ES module），不用写类型。pi 源码是 TypeScript，但 TypeScript = JavaScript + 类型标注；把类型去掉，剩下的语法完全一样。所以这页讲的东西两边通用。

1 · 声明变量：const / let

const result = 1;   // 声明后不再改指向——默认都用这个
let count = 0;      // 之后还会改的才用 let

在这段循环里：每一处赋值都要带 const。.mjs 是严格模式，写 result = callModel(...)（漏了 const）会直接报 ReferenceError: result is not defined。

2 · async / await：等异步结果

async function f() {           // 标 async，函数里才能用 await
  const x = await g();         // 等 g() 有结果了，再往下走
}

在这段循环里：runTool 是 async 的，await 必须加——不加的话 runTool(call) 返回的是一张「提货单」（Promise），你 push 进 msgs 的就不是工具结果本身，假模型也就永远看不到 toolResult，循环停不下来。练习里 callModel 恰好被写成了同步函数（await 一个非 Promise 会原样返回，加了无害）；但真 pi 里模型调用是走网络的异步操作，课里的 7 行伪代码按异步写。因为函数体里出现 await，runLoop 自己也要写成 async function runLoop(...)，调用处写 await runLoop(messages)。

3 · 箭头函数：给数组方法传「判断条件」

(c) => c.type === "toolCall"   // 读作：给一个 c，返回 c.type 是否等于 "toolCall"

在这段循环里：filter / some 需要一个「逐项判断」的小函数，用箭头函数就地写。等价于一个匿名函数，但更短。参数是数组里的一个元素（这里是一条内容块 c）。

4 · 数组四件套：.filter / .some / .push / .length

写法返回作用
arr.filter(fn)新数组只保留 fn 为真的项（原数组不动）
arr.some(fn)布尔任一项为真即 true
arr.push(x)新长度把 x 加到末尾
arr.length数字当前有几项

在这段循环里：result.content.filter((c) => c.type === "toolCall") 挑出工具调用；msgs.push(...) 把消息入栈；calls.length === 0 判断要不要退出。注意用 ===（严格相等），不用 =（= 是赋值）。

5 · for...of：逐个跑工具

for (const call of calls) {   // 依次把 calls 里每个元素取出来，叫 call
  ...
}

在这段循环里：calls 是一批工具调用，用 for...of 一个个跑。

关键：别把 for 写成方法

calls.for (...) 不是合法 JS——for 是关键字，只能是 for (const x of arr) { } 这种语句。arr.forEach(fn) 才是方法，但这里用 for...of 更直观（能 await）。

6 · 对象与数组字面量：一条消息长什么样

const msg = {
  role: "assistant",                     // { 键: 值 } 是对象
  content: [ { type: "text", text: "hi" } ]   // [ ] 是数组；content 是「内容块」数组
};
msg.content      // 用点取值
msg.content[0]   // 或下标取值

在这段循环里：模型返回的 result 是这样一个对象；它的 content 是数组，所以能 .filter(...)。工具调用块形如 { type: "toolCall", name: "read_file", arguments: {...} }，用 call.name、call.arguments 读。

7 · if / return：退出

if (calls.length === 0) return;   // 条件成立就结束这个函数

在这段循环里：这一句是唯一的正常出口；return 不带值，直接结束 runLoop。

对照版（annotated）

改完自己的版本、卡住了，才看这里。这 8 行能通过练习：

async function runLoop(msgs) {
  while (true) {
    const result = await callModel(msgs);                              // 1 整个数组发出去
    msgs.push(result);                                                 // 2 模型说的先入栈
    const calls = result.content.filter((c) => c.type === "toolCall"); // 3 挑出工具调用
    if (calls.length === 0) return;                                    // 4 没有就退出
    for (const call of calls) {                                        // 5 每个工具跑一遍
      msgs.push(await runTool(call));                                  //   结果入栈
    }
  }
}

报错 → 病因对照

你看到的多半是
ReferenceError: result is not defined赋值漏了 const / let
SyntaxError: Unexpected token语法不合法（如 calls.for (...) { }；或把关键字、保留词当方法名）
TypeError: x is not a function调用了不存在的名字（如 isToolCall、array 没定义）
一进来就 × 循环没有跑完：TODO...忘了删函数开头那句 throw new Error("TODO...")
× 循环没有跑完：callModel 已被调用 N 次循环停不下来。两种常见病因：① 退出条件写错；② runTool 前漏了 await，工具结果没真正入栈

自查清单（写完后逐条对）

  1. 函数头是 async function runLoop(msgs) {，且已删掉 TODO 那句 throw。
  2. await callModel(msgs) 的结果用 const 接住，紧接着 msgs.push(...)。
  3. 用 filter 把 content 里的 toolCall 挑出来。
  4. calls.length === 0 时 return。
  5. 对每个 call 调的是 runTool(call)（不是 runLoop！），await 后 push 进 msgs。
  6. 整个 while (true) 没有别的手动退出——靠第 4 条离开。
