包结构速查

字段/目录二次开发时的意义
bin把命令名映射到 CLI 文件。
main / types传统 JavaScript 入口与 TypeScript 声明入口。
exports公开且受控的包导入路径；新增子路径通常改这里。
dependencies运行期依赖；二次开发先复用已有能力。
devDependencies只服务构建、类型检查和测试。
examples/extensions进程内扩展 Pi 行为的首选学习入口。
examples/sdk把 Pi 作为库嵌入 Node.js 程序。
docs/rpc.md非 Node.js 或跨进程集成协议。
