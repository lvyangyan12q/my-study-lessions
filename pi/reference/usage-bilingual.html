Use Pi in the terminal / 在终端里用 Pi

Run pi from the folder you want to work in. Pi uses that folder to discover files, instructions, and configuration, and to group saved sessions. If you have not installed Pi or chosen a model yet, follow the Quickstart.
在你想工作的文件夹里运行 pi。Pi 用该文件夹发现文件、指令和配置，并给保存的会话分组。若还没安装或没选模型，先走 Quickstart。
Pi may ask whether you trust the working folder before loading its project resources. See Project trust.
加载项目资源前，Pi 可能先问你信不信任这个工作文件夹。见 Project trust。
The transcript shows your prompts, Pi's responses, tool calls, results and errors. You write prompts and commands in the editor. The footer shows the current folder, session, model, context usage, and accumulated usage and cost.
对话区显示：你的提示、Pi 的回应、工具调用、结果和错误。你在编辑器里写提示和命令。状态栏显示：当前目录、会话、模型、上下文用量，以及累计用量与花费。

Enter a prompt / 输入提示

Type a request and press Enter to send it. Use Shift+Enter to add a line, or press Ctrl+G to work on a longer prompt in your configured external editor.
输入请求后按 Enter 发送。Shift+Enter 换行；Ctrl+G 在已配置的外部编辑器里写更长的提示。
To include files or images:
要加入文件或图片：
Type @ to search for a file and add it to your prompt.
输入 @ 搜索文件并加入提示。
Press Tab to complete a path.
按 Tab 补全路径。
Paste an image or drag it into a compatible terminal.
粘贴图片，或把它拖进兼容的终端。

Follow Pi's work / 跟随 Pi 的工作

Pi shows each tool call and result while it works. Press Ctrl+O to expand or collapse tool output. Press Ctrl+T to show or hide thinking blocks.
Pi 工作时会显示每一次工具调用和结果。按 Ctrl+O 展开/折叠工具输出；按 Ctrl+T 显示/隐藏 thinking 块。
The startup header lists the instructions and resources Pi loaded. The editor border indicates the current thinking level. The footer updates as the model uses context and reports usage.
启动头列出 Pi 加载的指令与资源。编辑器边框表示当前 thinking 级别。状态栏随模型消耗上下文、报告用量而更新。
Pi does not ask before every tool call. Review commands and changed files, and use a sandbox for untrusted or unattended work. See Security.
Pi 不会在每次工具调用前都问你。自己 review 命令与改动的文件；不可信或无人值守的工作请用沙箱。见 Security。

Change direction / 改变方向

You can send more input while Pi is working:
Pi 工作时你仍可继续输入：
What you want / 你想Action / 操作
Adjust the current task
调整当前任务		Type a message and press Enter
Add work after the current task
追加后续工作		Type a message and press Alt+Enter
Return queued messages to the editor
把排队消息收回编辑器		Press Alt+Up
Stop the current task
停止当前任务		Press Escape
A message sent with Enter waits until the current response and its tool calls finish, then guides the next response. A follow-up sent with Alt+Enter waits until Pi finishes the current task. Aborting returns queued messages to the editor.
用 Enter 发的消息会等当前回应及其工具调用结束，然后引导下一次回应。用 Alt+Enter 发的 follow-up 会等 Pi 完成当前任务。中止（abort）会把排队消息退回编辑器。
Windows Terminal reserves some Alt shortcuts. See Terminal Setup for the Windows alternatives.
Windows Terminal 保留了部分 Alt 快捷键，Windows 替代方案见 Terminal Setup。

Change the model or settings / 改模型或设置

Type / to search the available commands. The commands you will use most often are:
输入 / 搜索可用命令。最常用的有：
/model selects a model. Press Ctrl+L to open the same selector.
/model 选模型；Ctrl+L 打开同一个选择器。
/thinking selects how much reasoning the current model uses. Press Shift+Tab to cycle through supported levels.
/thinking 选择当前模型用多少推理；Shift+Tab 在支持的级别间循环。
/login and /logout manage provider access.
/login 与 /logout 管理 provider 访问。
/settings changes common preferences.
/settings 修改常用偏好。
Prompt templates, skills, and extensions can add more commands to the same menu. See Choose a Model, Configuration, or the complete Slash Commands reference.
Prompt template、Skill、Extension 都能往同一菜单里加命令。见 Choose a Model、Configuration，或完整的 Slash Commands 参考。

Continue or start over / 继续或重开

Pi saves sessions automatically unless session persistence is disabled.
除非关闭了会话持久化，Pi 会自动保存会话。
/new starts a new session.
/new 开始新会话。
/resume opens another saved session.
/resume 打开另一个已保存会话。
/name gives the current session a recognizable name.
/name 给当前会话起个可辨认的名字。
/session shows its file, ID, message count, token usage, and cost.
/session 显示会话文件、ID、消息数、token 用量与花费。
Use /tree, /fork, or /clone when you want to explore another approach without losing existing work. Use /compact to reduce the conversation history sent to the model. See Sessions and Context for these workflows.
想在不丢已有工作的情况下探索另一条路，用 /tree、/fork 或 /clone。用 /compact 压缩发给模型的对话历史。这些流程见 Sessions and Context。
After leaving Pi, run pi --continue from the same folder to resume its most recent session.
离开 Pi 后，在同一文件夹里运行 pi --continue 恢复最近一次会话。

Run a terminal command / 跑终端命令

Prefix a command with ! to run it and include its output in the conversation:
命令前加 !：执行它，并把输出带进对话：
!git status
Use !! when you want to run a command without sending its output to the model.
想执行命令但不把输出发给模型，用 !!。

Copy, export, or share results / 复制、导出、分享

Press Ctrl+X or run /copy to copy the last assistant response. Use /export to save the session as HTML or JSONL.
按 Ctrl+X 或运行 /copy 复制上一条 assistant 回应。用 /export 把会话保存为 HTML 或 JSONL。
Use /share to upload the session and get a viewer link. By default, Radius authentication makes the artifact visible to your Radius organization; otherwise, Pi creates a private GitHub gist through the GitHub CLI. The sessionShareDestination setting can force either destination. Review the session first because it can contain prompts, tool output, file contents, and credentials exposed during the conversation.
用 /share 上传会话并得到查看链接。默认：已登录 Radius 时产物对你的 Radius 组织可见，否则 Pi 通过 GitHub CLI 建一个私有 gist；sessionShareDestination 可强制二者之一。分享前先自查会话——它可能含提示、工具输出、文件内容，以及对话过程中暴露的凭据。

Adjust the terminal / 调整终端

Fullscreen mode, the default, keeps the editor and status area fixed while the transcript scrolls within the terminal window. Regular mode uses the terminal's normal scrollback. Choose a mode through /settings or --tui-mode.
全屏模式（默认）固定编辑器与状态区，对话在终端窗口内滚动；普通模式用终端自身的回滚区。用 /settings 或 --tui-mode 选择模式。
Terminal support for mouse input, keyboard shortcuts, and inline images varies. See Terminal Setup for platform-specific configuration and Keybindings for every configurable shortcut. Run /hotkeys to inspect the shortcuts active in your current session.
终端对鼠标输入、键盘快捷键、内联图片的支持各不相同。平台配置见 Terminal Setup；所有可配置快捷键见 Keybindings。运行 /hotkeys 查看当前会话生效的快捷键。

Collect diagnostic information / 收集诊断信息

When troubleshooting terminal rendering or conversation state, run /debug. Pi writes the rendered terminal lines and current session messages to pi-debug.log in your agent directory.
排查终端渲染或会话状态问题时，运行 /debug。Pi 会把渲染出的终端行和当前会话消息写到你的 agent 目录下的 pi-debug.log。
Review this file before sharing it. It can contain prompts, model responses, tool output, file contents, and terminal data.
分享这个文件前先 review：它可能含提示、模型回应、工具输出、文件内容和终端数据。
